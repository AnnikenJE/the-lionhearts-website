# The Lionhearts — Guild Website

Official website for **The Lionhearts**, a World of Warcraft guild on **Darkmoon Faire (EU)**.

## Stack

- React 19
- TypeScript
- Vite

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Lint

```bash
npm run lint
```
