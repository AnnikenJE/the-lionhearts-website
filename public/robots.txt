# Everyone else: open, except the API (server routes, not pages) and the
# tier query variants, already noindex per page (see useTierFetch.ts).
# Character pages are cached separately for every tier, so a crawler walking
# every character in every tier fetches mostly uncached pages from Warcraft
# Logs. That uses up the shared API budget and leaves real visitors with
# incomplete parses.
User-agent: *
Allow: /
Disallow: /api/
